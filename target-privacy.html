Privacy Policy — Target

Last updated: 5 October 2026

Target ("the game") is developed by PraeliaLab ("we"). This policy explains what data the game uses and why.

What the game uses

  • Server list. When the game starts it downloads the list of game servers from a file hosted on GitHub Pages (kingspartakospt.github.io). GitHub receives your IP address to deliver that file, as with any web page.
  • Multiplayer data. Matches run on dedicated servers. To connect you and run the match, the server receives your network data (such as your IP address) and your in-game actions, and records connections in its logs. These logs are used only to run, fix and protect the servers and are kept only as long as needed for that.
  • Player name. The game sends a player name to the server, made from your computer name and a device ID. Other players in the match can see it.
  • Settings are saved on your device.
  • Downloads and any purchases or donations are handled by the store you use (for example itch.io). We never see your payment details.

The game shows no advertising, has no analytics or tracking tools and does not sell your data. We do not ask for your name, email or phone number.

Who processes it

GitHub, Inc. hosts the server list: GitHub privacy statement. The store you downloaded the game from has its own privacy policy.

Keeping and deleting data

To ask about or delete data related to you, write to praelialab@gmail.com. Uninstalling the game deletes the data saved on your device.

Children

The game is not directed at children under 13.

Contact

PraeliaLab — praelialab@gmail.com

Política de Privacidade — Target

Última atualização: 5 de outubro de 2026

O Target ("o jogo") é desenvolvido pela PraeliaLab ("nós"). Esta política explica que dados o jogo usa e para quê.

O que o jogo usa

  • Lista de servidores. Ao arrancar, o jogo descarrega a lista de servidores de um ficheiro alojado no GitHub Pages (kingspartakospt.github.io). O GitHub recebe o teu endereço IP para entregar esse ficheiro, como em qualquer página web.
  • Dados do multijogador. As partidas correm em servidores dedicados. Para te ligar e correr a partida, o servidor recebe os teus dados de rede (como o endereço IP) e as tuas ações no jogo, e regista as ligações nos seus logs. Estes logs servem só para manter, corrigir e proteger os servidores e são guardados apenas o tempo necessário para isso.
  • Nome de jogador. O jogo envia ao servidor um nome de jogador, feito a partir do nome do teu computador e de um identificador do aparelho. Os outros jogadores da partida podem vê-lo.
  • As definições ficam guardadas no teu aparelho.
  • Downloads e eventuais compras ou donativos são tratados pela loja que usas (por exemplo o itch.io). Nunca vemos os teus dados de pagamento.

O jogo não tem publicidade, nem ferramentas de análise ou rastreio, e não vende os teus dados. Não pedimos o teu nome, email nem telefone.

Quem os trata

A GitHub, Inc. aloja a lista de servidores: declaração de privacidade do GitHub. A loja de onde descarregaste o jogo tem a sua própria política de privacidade.

Conservação e eliminação

Para perguntares por dados relacionados contigo ou pedires que sejam apagados, escreve para praelialab@gmail.com. Desinstalar o jogo apaga os dados guardados no aparelho.

Crianças

O jogo não se destina a menores de 13 anos.
